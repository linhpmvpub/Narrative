# Scoped customer activity and DELL/SNDK profiles

SCOPED_ACTIVITY requires issuer/topic, product/infrastructure context and action groups within one sentence or heading. Matches retain original field offsets and disclose that a same-sentence topic match is not a verified party or commercial exposure. It does not join an issuer share-price headline with an unrelated project in the summary. Negative/cancelled activity can be relevant information without positive impact. Source/profile integrity, expiry, current revision, explicit narrative scope and graph traversal gates still apply.

Enabled bindings are now audited at profile staging: each explicitly selected narrative must have a sourced path from its factor, and the factor must belong to the company's structural component. This prevents a locally plausible factor/mechanism from becoming a silently disconnected rule. A rejected stage leaves the current pointer/version untouched. Implicit-scope legacy bindings need at least one reachable narrative. Disabled draft bindings can remain without routes.

Local DELL profiles distinguish ISG AI/traditional servers/networking/storage from CSG client PCs, financing/consumption choices and memory-component cost exposure. Named customers/suppliers are not inferred from unspecified groups. Local SNDK profiles distinguish NAND/SSD from WDC HDD, one reportable segment from three end markets, and three Flash Ventures entities from Kioxia. Wafer/funding evidence is not current capacity, orders or realized financial impact. Each new profile has ten required component areas, with explicit UNKNOWN where evidence was not reviewed.

Two independent AI reviews are used for development, not human gold. The first38-article/342-pair freeze exposed missing structural links; it remains unchanged, including its errors. The subsequent25-article/225-pair freeze excludes prior URLs and near-duplicates and uses the repaired profiles and narrower NVIDIA context. Cohorts with different profile versions are not pooled. The dataset sizes are below the acceptance targets; missing positive cases are not treated as successful validation.

Raw SEC filings, profiles, review rationales and frozen predictions remain under ignored source-cache paths. Public commits contain schema/code, synthetic tests, documentation and aggregate results only. Official NVIDIA and Dell blog RSS feeds supplement the existing catalog; published excerpts remain unverified. No real notification delivery, canonical fact creation or cloud data deployment is enabled.
