# Source-bound operating vocabulary

`engine.operating_vocabulary.audit_vocabulary(directory, bundle, binding_ids)` checks explicit new operating bindings against the profile's hash-verified source files. This initial importer accepts only official SEC archive HTML URLs with the same issuer CIK; other hosts, issuers, query strings and noncanonical paths are held. It does not verify the truth of a captured issuer statement. Each topic, own-issuer context and change term needs its own same-sentence evidence witness. Missing terms, adjacent-sentence coincidence, quoted speech, competitor attribution, conditional/future wording and negation fail closed using the same matcher as routing. Evidence spans and a profile digest are returned; the function never writes a profile, grants source permission or activates anything.

This gate verifies literal support, not the truth of an issuer assertion or the semantics of a causal path. An operator must still review product identity, narrative scope and source limitations. Existing profile schema/hash serialization is unchanged. The active registry and prior frozen evaluation artifacts are not rewritten.

## Development result

An isolated NVIDIA v10 adds two explicitly sourced bindings: a named-architecture ramp and named-platform growth. They retain the existing sourced systems anchor and explicit narrative scope. Growth is topical context for a deployment narrative, not proof of demand, customer orders or financial impact. The supporting source has incomplete whole-report context, and its filing-date publication time uses a conservative end-of-day bound rather than pretending an observed publication instant.

On the already-exposed five-pair recent-period sample, development replay improves TP0/FP0/TN3/FN2 to TP2/FP0/TN3/FN0. The two positives share one excerpt. The older twenty-pair sample remains TP2/FP0/TN10/FN1/unresolved7; the scoped five-pair sample remains TN4/unresolved1. All original freezes are preserved. These are post-label development diagnostics, not fresh blind validation. Fourteen synthetic counterfactual checks cover wrong issuer, quotes, future wording, negation, competitor context and split sentences. Synthetic checks are not market accuracy evidence.

Same-sentence routing remains mandatory. A product vocabulary expansion is sufficient for these examples; cross-sentence segment attribution is deliberately not implemented without an explicit evidence-backed relation. Independent vocabulary audits are separate from independent relevance labels. Next validation must exclude all exposed economic-period packets and use new labeler contexts after freezing predictions. Do not switch active profiles or release a real operating card on the strength of this development replay alone.

Two separate-context AI vocabulary auditors approved both proposed bindings for experimental informational use, retaining original source limitations and excluding financial/causal inference. All four candidates in the two already-scoped pools are now prior-period exposures; readiness produced no new predictions or labels. A different source period must be acquired and independently scoped for the next blind round. Final CI 45321535571 passed 766 tests on SQLite and 766 on PostgreSQL.
