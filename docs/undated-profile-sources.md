# Undated official profile sources

An official product or technical page can describe a useful structural exposure without stating its original publication date. Store `published_at: null` and explicit `unknown_publication` metadata: source kind, uncertainty basis and review note. A displayed update date is separate metadata, never an invented original publication date. Legacy dated sources retain their serialized form.

The source URL, captured bytes, SHA256, retrieval time and literal evidence still require review. A label such as OFFICIAL_PRODUCT_PAGE records that review; it does not automatically authenticate the publisher. Redirected listings and search snippets are not the original page. Missing dates are not permission to fill missing financial numbers or conditions.

Relationships citing these sources cannot have validity or knowledge before capture. Profile availability must follow capture; normal graph activity/expiry/withdrawal checks apply. This conservative operational validity is not a claim about when the physical relationship first existed. The atlas displays the original publication date as unknown and retains acquisition time separately.

Dated events, period metric observations, financial extraction and financial reporting-scope bindings require dated sources. Undated pages cannot backfill these records. Other qualitative profile evidence may use the explicit unknown-date contract. Quantified financial effect remains unknown unless separately established.

## Resource deployment context

The shared readiness matcher supports POWER, WATER, COOLING and CONSTRUCTION, each opt-in with a literal resource/market quote and a sourced mechanism. Product cooling availability can condition customer deployment; that does not establish manufacturing interruption, construction permits, actual orders or a realized demand change. No ticker-specific branch is needed.

Resource and condition must form a bounded phrase in the same market sentence. Unrelated component capacity, another industry, negation, cross-field donation and incidental capability descriptions retain existing guards. New resource matches remain `context_only`/BACKGROUND, with no automatic priority or financial direction/magnitude/horizon.

Validation covers source metadata/chronology, prevention of historical backfill, dated financial safeguards, atlas serialization and renamed synthetic companies with resource-specific positive/negative examples. Run the locked benchmark after code changes and again after database changes; report relevance and priority separately. This is exposed AI regression, not independent causal verification.
