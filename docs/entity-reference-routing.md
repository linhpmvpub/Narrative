# Source-bound entity context

Profiles can attach a reviewed entity reference to an RSS factor binding. References distinguish legal entities, groups, brands, and unnamed affiliates. A group name is contextual evidence, not an alias that resolves an unnamed affiliate. Unresolved affiliates cannot carry searchable names or power a binding.

Every reference names an existing party node and incident source-backed relationships, supplies literal names visible in source quotations, and records scope, unknowns and a review window of at most 90 days. Exact entity references require a legal-entity node bearing one of those names. These structural checks do not replace semantic source review.

Routing requires all three existing economic term groups, a current reference and supporting relationships, the factor-to-narrative route and a separate party-to-narrative route. Expired, revoked, disputed or overlapping ambiguous references withhold the match. Source integrity and current RSS revisions remain checked on each read. Ambiguity detection is profile-local; this is not a global entity registry or a general entity-resolution model.

Cards include exact name spans, reference scope, quoted evidence, unknowns and the contextual route. Both `identity_merged` and `news_party_verified` remain false, including for curated exact legal references: identifying a name in the profile does not verify the party or claim in a news excerpt. Stance remains related information, impact unknown, notifications disabled, and the global graph is unchanged.
