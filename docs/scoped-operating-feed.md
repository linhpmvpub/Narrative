# Exact-passage scope and reviewed operating cards

Whole-filing incompleteness and the interpretability of one exact passage are separate decisions. `scoped_operating_passages.approved_rows` requires two distinct AI source reviews bound to an immutable candidate packet and exact quote hash. Both must approve `EXACT_PASSAGE_INFORMATIONAL_ONLY`, require no external context for that excerpt, and agree on a source-cited economic period. Original HTML/text hashes, transformation, issuer/accession URL and offsets are checked again. Disagreement holds the passage. This never clears the original whole-filing limitations or grants source permission for canonical ingestion.

`freeze` excludes previously reviewed issuer-periods, source hashes and near-duplicate text before using the shared current-profile freezer. Raw scope limitations and original offsets travel with the reviewer packet. Predictions are separate and frozen before new-context relevance labels. Source reviewers are not reused as blind relevance labelers. This is targeted text relevance, not historical as-of performance, human gold or population accuracy.

The first scoped batch approved three excerpts but excluded two previously evaluated periods, leaving one Micron company-description passage/five pairs. New independent reviewers agreed on four negatives and disagreed on one pair, retained as insufficient context. No positive validation is available from that batch. Boilerplate must not be promoted as a new operating event merely because it mentions a company's products.

Authenticated GET `/api/v0/news/reviewed-operations` projects only canonical SEC claims that pass the same latest-version, independent-review, source permission, identity, hash, exact-span and lifecycle checks as reviewed-role cards. It selects only `ISSUER_OPERATING_CONTEXT` bindings with matching trusted issuer CIK and current sourced product/narrative paths. Operating and supplier-role cards have separate identities and sections; operating cards do not claim a buyer/supplier relationship. Impact remains unknown, graph changes and delivery disabled.

The mobile gateway permits only GET for this new route. The private `/news` page shows a separate operating section, source links, profile paths, AI review disclosure and decision traces. Failure, refresh, visibility changes and logout clear stale cards. The browser test uses an explicitly synthetic response in the browser only; it never creates a real event. Empty real results are valid while profiles/claims remain unapproved for activation.

This is projection capability, not automatic activation of experimental profiles. Source scope reviews, benchmark labels, production source permission and canonical review/ingestion are distinct artifacts and must not be silently substituted for one another.
