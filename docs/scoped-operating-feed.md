# Exact-passage scope and reviewed operating cards

Whole-filing incompleteness and the interpretability of one exact passage are separate decisions. `scoped_operating_passages.approved_rows` requires two distinct AI source reviews bound to an immutable candidate packet and exact quote hash. Both must approve `EXACT_PASSAGE_INFORMATIONAL_ONLY`, require no external context for that excerpt, and agree on a source-cited economic period no later than the filing date. Original HTML/text hashes, transformation, issuer/accession URL and offsets are checked again. Disagreement holds the passage. This never clears the original whole-filing limitations or grants source permission for canonical ingestion.

`freeze` excludes previously reviewed issuer-periods, source hashes and near-duplicate text before using the shared current-profile freezer. Raw scope limitations and original offsets travel with the reviewer packet. Predictions are separate and frozen before new-context relevance labels. Source reviewers are not reused as blind relevance labelers. This is targeted text relevance, not historical as-of performance, human gold or population accuracy.

The first scoped batch approved three excerpts but excluded two previously evaluated periods, leaving one Micron company-description passage/five pairs. New independent reviewers agreed on four negatives and disagreed on one pair, retained as insufficient context. No positive validation is available from that batch. Boilerplate must not be promoted as a new operating event merely because it mentions a company's products.

Authenticated GET `/api/v0/news/reviewed-operations` projects only canonical SEC claims that pass the same latest-version, independent-review, source permission, identity, hash, exact-span and lifecycle checks as reviewed-role cards. It selects only `ISSUER_OPERATING_CONTEXT` bindings with matching trusted issuer CIK and current sourced product/narrative paths. Operating and supplier-role cards have separate identities and sections; operating cards do not claim a buyer/supplier relationship. Impact remains unknown, graph changes and delivery disabled.

The mobile gateway permits only GET for this new route. The private `/news` page shows a separate operating section, source links, profile paths, AI review disclosure and decision traces. Failure, refresh, visibility changes and logout clear stale cards. The browser test uses an explicitly synthetic response in the browser only; it never creates a real event. Empty real results are valid while profiles/claims remain unapproved for activation.

This is projection capability, not automatic activation of experimental profiles. Source scope reviews, benchmark labels, production source permission and canonical review/ingestion are distinct artifacts and must not be silently substituted for one another.

## Recent-period validation and remaining coverage gap

A second acquisition captured three recent issuer earnings families/nine documents locally. Fixed unquoted operating-text sampling selected one NVIDIA excerpt; the other two families were not padded into the sample. Two independent source auditors approved only the exact passage and retained unaudited/pending-report and other source limitations. New-context relevance reviewers then independently labeled the five narrative pairs after predictions were frozen.

Both reviewers agreed: two relevant, three not relevant. Frozen experimental-profile routing returned TP0/FP0/TN3/FN2, with no unresolved labels. The two positives share one excerpt, so they are not two independent event observations. This is a targeted AI reference test, not human gold or market-wide accuracy.

Post-label inspection verified unchanged profile and freeze hashes. Both NVIDIA operating bindings returned no match: their vocabulary requires Data Center and our Blackwell in the same sentence; the newer excerpt describes a different named architecture and separates the segment context from the activity sentence. The demand rule also requires literal demand. Do not remove issuer attribution or sentence boundaries merely to fit this example. Next work should add source-backed product/architecture identities and carefully bounded segment attribution, with negative controls and a different economic-period evaluation before activation. Any replay on this now-exposed passage is development only.

Active profiles remain NVIDIA v8/Micron v2; the experimental NVIDIA v9/Micron v3 registry stays isolated. No real operating card has been released. Benchmark scope approval cannot substitute for production claim review or source permission.
