# Reviewed-source ingestion checkpoint — 2026-11-21

Implemented migration 0006, immutable source-permission history and provenance receipts, plus a reviewed SEC adapter writing the existing canonical event/document/evidence tables. Operator-only endpoints explicitly approve/revoke source rights and issuer identity, ingest a specified draft/version, and read canonical snapshots at an as-of cutoff. No automatic approval, graph activation, scoring, feed projection or delivery is performed.

The adapter rejects absent/expired/revoked/mismatched permissions, stale draft/permission versions, unapproved or non-independent reviews, capture/citation/issuer/basis inconsistencies and future/inconsistent clocks. It checks rights both at the admission cutoff and processing time. Event/version availability is the actual processing timestamp, never backdated to the filing's publication/capture date. Unknown exact occurrence time, evidence quality and materiality remain null/UNKNOWN.

Writer locking, idempotency receipts and unique canonical keys serialize concurrent operators. Explicit reprints attach evidence without creating a version, including reprints of a superseded original; corrections require changed facts and the latest ingested canonical target. All canonical/document/evidence/receipt writes commit together. Current snapshots withhold invalid latest versions rather than reverting to older facts; prior snapshots remain reproducible across later revocation.

Validation evidence: `reviewed-ingestion-sqlite-tests.xml`, `reviewed-ingestion-postgresql-tests.xml`, `reviewed-ingestion-container.json`, `reviewed-ingestion-local-state.json`, `reviewed-ingestion-preview.json`. **Final full suites: SQLite 228 passed (225.99s); PostgreSQL 228 passed (246.97s).** Each has one upstream Starlette/httpx deprecation warning; zero failures/errors/skips. The focused 20-case suite also passed after the correction fix. Ruff and mypy (48 engine files) passed. Container smoke ran from /tmp using the installed wheel, fabricated evidence, migration 0006, two operator identities, separate rights permission and canonical ingestion; exactly one event/receipt and zero alerts/cards were created in that disposable container.

This was corrected, the focused 20-case suite passed again, and both complete database suites were rerun on the corrected code. No failure was accepted as a release exception.
